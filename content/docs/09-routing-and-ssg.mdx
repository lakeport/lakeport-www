# Routing, LawfulUrlCodec, and SSG

While backend REST APIs speak standard JSON, URL path segments are one place where every app defines its own custom string parser and formatter. `LakeportRouter` backs your URL router with an inductive `Route` type and a small `LawfulUrlCodec` round-trip proof so internal links and pre-rendered SSG paths never drift out of sync.

## 1. Define your Route type and LawfulUrlCodec

List every screen in your application as an inductive type in `src/Routes.lean`:

```lean title="src/Routes.lean"
inductive SiteRoute where
  | home
  | whyLean
  | ecosystem
  | showcase
  | docsIndex
  | docsPage (slug : DocSlug)
  deriving DecidableEq, Repr, Inhabited
```

Implement `UrlCodec SiteRoute` by converting between `SiteRoute` and path segments (`List String`), then prove `LawfulUrlCodec` in `src/SiteLaws.lean`:

```lean title="Round-trip URL codec and theorem"
def routeCodec : UrlCodec SiteRoute where
  toSegments
    | .home => []
    | .whyLean => ["why-lean"]
    | .ecosystem => ["ecosystem"]
    | .showcase => ["showcase"]
    | .docsIndex => ["docs"]
    | .docsPage d => ["docs", d.slug]
  fromSegments?
    | [] => some .home
    | ["why-lean"] => some .whyLean
    | ["ecosystem"] => some .ecosystem
    | ["showcase"] => some .showcase
    | ["docs"] => some .docsIndex
    | ["docs", raw] => DocSlug.parse? raw |>.map .docsPage
    | _ => none

instance : LawfulUrlCodec routeCodec where
  roundtrip r := by cases r <;> first | rfl | (rename_i d; cases d <;> rfl)
```

If an agent adds a new `DocSlug` chapter or screen constructor and forgets `fromSegments?`, `lakeport check` stops immediately with the unhandled case.

## 2. Pure navigation state and RouterShell

`RouterState Route` models your root route, a push/pop back-stack, an optional modal sheet, and an optional side drawer as pure Lean values. Its companion theorem `RouterState.stepBack_decreases` proves that pressing Back closes open overlays first and pops the stack until reaching the root screen.

Wrap your top-level `.lp` view in `<RouterShell>` so `boot.mjs` synchronizes `window.history`:

```lp title="Synchronizing browser history in src/App.lp"
def view (s : AppState) : V :=
  let url := routePath s.router.activeRoute
  <RouterShell url={url} canBack={s.router.canGoBack}>
    <div class="site-shell" data-theme={s.theme.attr}>
      {headerView s}
      {routeBody s}
      {footerView}
    </div>
  </RouterShell>
```

Forward route transitions (`history.pushState`) reset scroll position to the top of the document, while browser Back/Forward (`popstate`) preserves native scroll restoration.

## 3. Static site generation (SSG) from compiled WebAssembly

When `[lakeport.web] mode = "ssg"` is configured in `lakefile.toml`, `lakeport build web --release` runs `ssg-prerender.mjs` in Node.js against your actual `app_lp2.wasm` binary for every URL in `ssgRoutes`:

1. Node boots `app_lp2.wasm`, navigates to `/docs/versioned-contracts`, and serializes the resulting `ViewApi` + `LPST` frame into complete `dist/web/docs/versioned-contracts/index.html` with `data-lp-id` hydration attributes.
2. In the browser, static HTML paints immediately before WebAssembly finishes downloading.
3. When `boot.mjs` mounts on a matching `data-lp-ssg-route`, `DomRenderer.hydrate` binds to the existing DOM nodes in place without recreating elements or causing layout shift.

<Callout kind="note" title="Current URL parser limitation (?query and #hash)">
`LakeportRouter.Url.parseUrl` currently strips `?query` parameters and `#hash` fragments before passing path segments into `fromSegments?`. Apps that persist filter state in URLs should encode filter segments into the path (for example `/orders/status/open`) until structured query codecs land in `lakeport-router`.
</Callout>
