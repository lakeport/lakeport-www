# Routing, LawfulUrlCodec, and SSG

Broken internal links and mismatched client/server routes are completely avoidable when URLs are backed by an inductive type and a round-trip proof.

## 1. Define your Route sum and UrlCodec

Start in `src/Routes.lean` by listing every valid screen in your application as an inductive type:

```lean title="src/Routes.lean"
inductive SiteRoute where
  | home
  | whyLean
  | ecosystem
  | showcase
  | docsIndex
  | docsPage (slug : DocSlug)
  deriving DecidableEq, Repr, Inhabited
```

Next, implement `LakeportRouter.UrlCodec SiteRoute` by mapping between `SiteRoute` and URL path segments (`List String`), and prove `LawfulUrlCodec`:

```lean title="Proving URL round-trip Invertibility"
def routeCodec : UrlCodec SiteRoute where
  toSegments
    | .home => []
    | .whyLean => ["why-lean"]
    | .ecosystem => ["ecosystem"]
    | .showcase => ["showcase"]
    | .docsIndex => ["docs"]
    | .docsPage s => ["docs", s.slug]
  ofSegments
    | [] => some .home
    | ["why-lean"] => some .whyLean
    | ["ecosystem"] => some .ecosystem
    | ["showcase"] => some .showcase
    | ["docs"] => some .docsIndex
    | ["docs", raw] => (DocSlug.parse? raw).map .docsPage
    | _ => none

instance : LawfulUrlCodec routeCodec where
  ofSegments_toSegments := by
    intro r
    cases r with
    | docsPage s => cases s <;> rfl
    | _ => rfl
```

That four-line `LawfulUrlCodec` instance guarantees that every `SiteRoute` formats to a canonical path that `routeCodec.parseUrl` parses right back to the exact same `SiteRoute`.

## 2. Pure navigation stacks and RouterShell

`LakeportRouter.RouterState Route` models root tabs, pushed screens, modal sheets, and mobile drawers in pure Lean, with deterministic back-button priority (`sheet -> drawer -> pushed stack`) and a proved decreasing termination measure (`stepBack_decreases`).

Wrap your root view in `<RouterShell url={currentUrl} canBack={canBack}>`:

```lp title="Wrapping the root view"
<RouterShell url={routeCodec.formatPath s.router.activeRoute} canBack={s.router.canGoBack}>
  <div class="site-shell">
    {renderPage s}
  </div>
</RouterShell>
```

On the web, `RouterShell` synchronizes `history.pushState` and `popstate` events cleanly with your Lean state. For mobile host shells, `canBack` also exposes an explicit boolean signal for back-gesture integration as native adapters land.

## 3. Static site generation (SSG) and commit-0 hydration

Marketing pages and documentation sites need instant first paint and clean HTML for search engines and `curl` readers. Enable SSG in `lakefile.toml`:

```toml title="lakefile.toml"
[lakeport.web]
mode = "ssg"
ssgRoutes = [
  "/",
  "/why-lean",
  "/ecosystem",
  "/showcase",
  "/docs",
  "/docs/introduction"
]
```

During `lakeport build web --release`, Lakeport:

1. Compiles your Lean application to `dist/web/app.wasm`.
2. Boots `app.wasm` in Node for each route in `ssgRoutes`, sends `.router (.navigate route)`, and serializes the exact resulting view tree to `dist/web/<route>/index.html`.
3. When a visitor loads the page in a browser, static HTML paints immediately before WebAssembly finishes streaming. Once `app.wasm` initializes at commit `0`, `dom-renderer.mjs` attaches to the existing DOM nodes in place with **zero node creations** and **zero layout shift**.
